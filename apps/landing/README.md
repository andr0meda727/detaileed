# @detaileed/landing

Marketing page for studio owners: the product pitch plus `AppDemo`, a clickable mock of the dashboard
that runs on hard-coded data (no API, no sign-in). Static Vite + React + Tailwind site.

```bash
pnpm --filter @detaileed/landing dev     # http://localhost:4000
pnpm --filter @detaileed/landing build   # static files in dist/
```
